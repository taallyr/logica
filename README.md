# 🧠 Logica

Exercícios de Lógica com Python - Uma coleção de desafios e soluções para aprender e praticar conceitos fundamentais de programação.

## 📋 Descrição

Este repositório contém uma série de exercícios práticos focados em lógica de programação usando Python. Ideal para iniciantes que desejam fortalecer suas habilidades de resolução de problemas e compreensão de algoritmos.

## 🎯 Objetivo

- Reforçar conceitos fundamentais de programação
- Desenvolver habilidades de resolução de problemas
- Praticar lógica computacional
- Explorar diferentes abordagens para solucionar problemas

## 🛠️ Tecnologias

- **Linguagem**: Python 3.x
- **Tipo**: Exercícios Educacionais

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/taallyr/logica.git
cd logica
```

2. Execute os exercícios:
```bash
python nome_do_exercicio.py
```
